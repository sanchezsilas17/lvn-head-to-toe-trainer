# LVN Head-to-Toe Assessment Trainer

A Progressive Web App (PWA) for LVN students to practice head-to-toe assessments and medical terminology.

**Made for Margaret, future LVN. Built by Erica.**

## Live App

Once GitHub Pages is enabled, the app is available at:

**https://sanchezsilas17.github.io/lvn-head-to-toe-trainer/**

### How to enable GitHub Pages (one time)

1. Go to the repository **Settings → Pages**
2. Under "Build and deployment", set Source to **Deploy from a branch**
3. Select branch **main** and folder **/ (root)**
4. Click **Save**

The site will be live in 1–2 minutes.

## Install as Chrome App / PWA

- Open the live URL in **Chrome** (desktop or Android)
- Look for the install icon in the address bar, or the "Install app" button that appears in the header
- On iPhone/iPad: use Safari → Share → Add to Home Screen

Works offline after the first load.

## Features

- Interactive anterior/posterior body map
- Assessment terms, normal & abnormal findings for every region
- Speech practice (say the term)
- Quizzes (Tap it / Name it)
- Full medical terminology glossary, abbreviations, flashcards, and tests
- Score tracking
